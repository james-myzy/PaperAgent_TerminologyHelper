# 术语透视 · 便携版（免安装）

> 论文原文完整保留，术语自动标黄；点一下就着地解释，读完还停在原文里。

这个文件夹是一个**自带运行环境**的完整程序：里面已经放好了 Node.js 运行时和全部依赖，
目标电脑**不需要安装 Node.js、npm 或任何开发工具**，双击就能用。

---

## 一、三步启动

1. 把整个文件夹解压到任意位置（路径别太深，中文路径也可以）；
2. 双击 **`启动.bat`**；
3. 等 1–3 秒，浏览器会自动打开。没打开就手动访问窗口里打印的地址，默认是
   `http://127.0.0.1:8787`（端口被占用会自动换 8788、8789…，以窗口显示为准）。

关闭服务：直接关掉那个黑色窗口，或按 `Ctrl + C`。

第一次打开页面后，左下角「模型 API Key」点「填写」，把 Key 粘进去保存（会记住）。
不填也能用，只是进入离线演示模式（界面、高亮、导出都能用，回答内容是脚本化的）。

---

## 二、这个版本能做什么

- 上传 PDF / Word / TXT / MD，自动解析并识别术语（词库 + 大模型双引擎）；
- 正文术语黄色高亮，点一下就地弹出三段式解释（专业定义 / 上下文释义 / 相关引申）；
- PDF「版式」视图：原文件逐页渲染，双栏、公式、表格原样保留；
- **双语对照**：顶栏开关，原文一段、译文一段交替出现，逐段生成，译过的段落不重复花钱；
- 划选或框选一段 → 「解释选段」；
- 右侧术语汇总：搜索、跳回原文、自己加词、删词；
- 论文内搜索（Ctrl+F）、导出带高亮的 Word、智能体抽屉（8 个工具）。

## 三、文件夹里都是什么

```
paper-agent-portable/
├─ 启动.bat            一键启动（推荐用这个）
├─ start.bat           同内容，英文名
├─ README.md           本文件：文件说明与排错
├─ 使用说明.txt         给第一次用的人看的三分钟指南
├─ runtime\
│  ├─ node.exe         Node.js 24 运行时（约 89 MB），程序靠它跑起来
│  └─ LICENSE-node.txt Node.js 的许可证说明
└─ app\
   ├─ server\          服务端：文档解析、术语识别、翻译、导出、智能体
   ├─ web\             已构建好的网页界面
   ├─ node_modules\    运行所需依赖（docx / mammoth / pdfjs 等）
   ├─ docs\            插件说明与便携版说明
   ├─ examples\        示例素材
   ├─ fixtures\        自测用样例
   ├─ launcher.mjs     启动器：选端口、开浏览器、报错提示
   ├─ .env.example     模型配置模板（首次启动自动复制成 .env）
   └─ data\            运行时生成：上传的论文、术语、译文、导出的 Word
```

`data\` 目录是程序自己建的：想彻底重置就删掉它；换电脑就把整个文件夹拷走，`data` 一起带走。

## 四、系统要求

- Windows 10 / 11，64 位；
- 不需要联网也能打开界面（离线演示模式）；要用真实模型需要能访问模型接口；
- 磁盘占用：解压后约 138 MB。

## 五、常见问题

**双击后窗口一闪而过**
说明启动失败。右键 `启动.bat` → 以管理员身份运行；或打开 cmd，把 `启动.bat` 拖进去回车，
就能看到具体报错。

**Windows 提示“已保护你的电脑”**
点「更多信息」→「仍要运行」。内置的 `node.exe` 是官方 Node 运行时，没有数字签名所以会提示。

**端口 8787 被占用**
启动器会自动往后找 8787–8805，窗口里打印的就是实际地址。

**杀毒软件报警或删掉 node.exe**
把整个文件夹加入白名单。内置运行时来自 Node.js 官方发行包。

**页面能打开，但 AI 不回答**
检查首页「模型 API Key」是否已配置、是否有效；也在窗口里看有没有模型接口的报错。

**双语对照一直显示“翻译中…”**
每段译文是串行排队生成的（并发 3 批），长论文会持续几分钟；译好的段落会立刻出现，
不用等整篇。若长时间不动，看窗口里的报错。

**想把数据搬到另一台电脑**
把整个文件夹拷过去即可；只想要论文和导出的 Word，就只拷 `app\data\`。

**怎么卸载**
删掉这个文件夹就行，不写注册表、不装服务。
